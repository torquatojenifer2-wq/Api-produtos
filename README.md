# 🛒 Produtos API - Spring Boot REST API

API RESTful para gerenciamento de produtos desenvolvida com Spring Boot, Spring Data JPA e banco de dados H2.

---

## 📌 Sobre o Projeto

Este projeto foi construído progressivamente a partir dos conceitos fundamentais do Spring Framework:
- **Módulo 1:** Criação da estrutura base REST e manipulação de dados em memória.
- **Módulo 2:** Integração com Spring Data JPA, mapeamento de entidade e persistência de dados utilizando o banco em memória H2.

---

## 🚀 Tecnologias Utilizadas

- **Java 17 / 21**
- **Spring Boot 3.x / 4.x**
- **Spring Web** (Criação dos Endpoints REST)
- **Spring Data JPA** (Persistência e Mapeamento ORM)
- **H2 Database** (Banco de dados em memória)
- **Apache Maven** (Gerenciador de dependências)
